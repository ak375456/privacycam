# Security policy

## Supported versions

Security and privacy fixes are provided for the latest App Store and Google Play
release and the current default branch.

## Reporting a vulnerability

Do not disclose a security or privacy vulnerability in a public issue.

Email `ak375456@gmail.com` with:

- a concise description of the issue;
- affected platform and app version;
- reproduction steps using synthetic data;
- the likely privacy or security impact; and
- any suggested mitigation.

Do not attach unredacted personal photos, identity documents, payment
credentials, signing keys, or other sensitive records. A minimal synthetic
proof of concept is preferred.

You should receive an acknowledgement within seven days. No bounty or payment
is promised unless agreed in writing before work is performed.
