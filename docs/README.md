# PrivacyCam legal and support website

This folder contains the static PrivacyCam privacy policy, terms, and support
site intended for GitHub Pages or another static host.

Routes:

- `/` — legal and support landing page
- `/privacy.html` — privacy policy
- `/terms.html` — terms of service

Before publishing changes:

1. Confirm the support email is current in all three HTML pages.
2. Check that the effective dates are accurate.
3. Review the policy against the current app dependencies and store disclosures.
4. Verify all links and render the pages on mobile and desktop widths.

The app's source-code licence is separate from the end-user terms for the
official store application. Section 3 of `terms.html` explains that distinction.
